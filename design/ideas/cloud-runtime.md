# クラウドランタイム

> ステータス：アイデアレベル
> 最終更新：2026-05-08

ローカルの MIDI / OSC をブリッジ経由でクラウド側のランタイムに橋渡しする構成。初期スコープ・近期ロードマップとも無関係。現時点の設計判断が将来この形を潰さないかを点検する目的のメモとして残す。

## 想定ユースケース

- 人が介在しない IoT 同士の連携で、24/7 稼働や常時接続が必要なケース（速度よりも到達性・冪等性が要件になる）
- オンラインセッション用途（Syncroom 系）で、複数人のパフォーマンスをクラウド経由で同期させるケース（レイテンシ・ジッタ・クロック同期が要件になる）

## 構成のイメージ

ローカル側は USB MIDI / OSC を拾って WebSocket 等で流す薄いブリッジに留め、ランタイム本体はクラウドで動かす。

## 本格化させる場合の論点

要件化のタイミングで別途整理する:

- セッション概念の一級化
- イベントの時刻基準
- 認証 / テナント分離
